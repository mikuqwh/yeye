# 视觉与语音开发

- `PORTING_REVIEW.md`：现有算法的移植审查与实现建议。
- `PROGRESS_2026-11-02.md`：视觉侧最近一次进展记录（板卡/固件实测、已验证与未验证边界、当前阻塞、下一步）。
- `PROTOCOL_ADOPTION.md`：视觉侧对主控 20 字节结果包的确认与字段映射；规格入口仍是 `../control/docs/protocol_v1_draft.md`。
- `src/`：板端 CanMV 脚本与 PC 端离线标定脚本。
- `reference_code/`：原始C示例及头文件，尚未形成可直接运行的车载工程。
- `references/`：图像处理辅助文档。
- `data/`：样本与示例数据，包含二值图像表格和 `lane_2026-11-02/` 桌面车道典型样本。
- `evidence/`：视觉单模块的离线指标与叠加图，按日期分目录。

新增可运行视觉代码放 `src/`，语音代码放 `audio/`，需要时创建。参考代码与正式实现分开保存；图像样本可按场景在 `data/` 下分类。整车试跑证据统一放 `../testing/`。
